# Adivina el Número con Vite

Juego desarrollado con Vite y JavaScript Vanilla.

## Funcionamiento

La aplicación genera un número aleatorio entre 1 y 100.

El jugador debe intentar adivinarlo. Después de cada intento, el juego indica
si el número secreto es mayor o menor.

## Funcionalidades

- Generar un número aleatorio.
- Validar números entre 1 y 100.
- Mostrar pistas.
- Contar intentos.
- Mostrar el historial de números ingresados.
- Reiniciar el juego.
- Guardar la mejor puntuación con localStorage.

## Tecnologías
