# Gestión de Biblioteca con Callbacks y JSON

Aplicación de consola desarrollada con JavaScript para gestionar el inventario de una biblioteca.

## Funcionalidades

- Consultar todos los libros.
- Agregar nuevos libros.
- Actualizar la disponibilidad de un libro.
- Simular la lectura de datos de forma asincrónica.
- Simular la escritura de datos usando callbacks.

## Conceptos utilizados

- JSON
- `JSON.parse()`
- `JSON.stringify()`
- Callbacks
- `setTimeout`
- Métodos de arreglos como `forEach`, `find` y `push`
