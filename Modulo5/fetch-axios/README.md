# Consumo de API con Fetch y Axios

Aplicación web que consume la API de Rick and Morty utilizando Fetch y Axios.

## Funcionalidades

- Obtener personajes usando Fetch.
- Obtener personajes usando Axios.
- Mostrar nombre, imagen, estado, especie y origen.
- Mostrar mensajes de carga.
- Manejar errores de red y respuestas HTTP.
- Desactivar los botones mientras se realiza una solicitud.

## Tecnologías

- HTML
- CSS
- JavaScript
- Fetch API
- Axios
- Rick and Morty API
