# Exploración Espacial con Node.js y npm

Aplicación de consola para registrar y mostrar una lista de planetas favoritos.

## Funcionalidades

- Mostrar todos los planetas.
- Mostrar nombre, descripción, tipo y año de descubrimiento.
- Buscar un planeta por nombre.
- Ejecutar la aplicación mediante scripts de npm.

## Conceptos utilizados

- Node.js
- npm
- package.json
- Módulos CommonJS
- require
- module.exports
- Arrays
- Objetos
- forEach
- find
