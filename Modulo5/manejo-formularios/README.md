# Registro de Eventos

Formulario web para registrar asistentes a un evento.

## Funcionalidades

- Captura nombre, correo y teléfono.
- Permite seleccionar intereses.
- Permite elegir un horario.
- Permite seleccionar fecha y hora.
- Permite adjuntar un archivo opcional.
- Muestra mensajes personalizados de validación.
- Muestra un resumen cuando el registro es válido.

## Validaciones

- Nombre de al menos 3 caracteres.
- Nombre compuesto solo por letras y espacios.
- Correo electrónico válido.
- Teléfono de 10 dígitos.
- Al menos un interés seleccionado.
- Horario obligatorio.
- Fecha actual o futura.
- Archivos PDF, JPG o PNG.
- Tamaño máximo de archivo de 2 MB.
