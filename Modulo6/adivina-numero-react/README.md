# Adivina el Número con React

Proyecto realizado con React y Vite para practicar renderizado condicional y composición de componentes.

## Objetivo

Crear un juego interactivo en el que el usuario debe adivinar un número aleatorio entre 1 y 100.

## Funcionalidades

- Generación de un número aleatorio
- Ingreso de números por parte del usuario
- Pistas indicando si el número es mayor o menor
- Conteo de intentos
- Mensaje de éxito al acertar
- Reinicio del juego
- Uso de la tecla Enter para comprobar el número

## Conceptos utilizados

- React
- Vite
- JSX
- `useState`
- Renderizado condicional
- Operador `&&`
- Condicionales `if`
- Props
- `props.children`
- Composición de componentes
- Componentes funcionales
