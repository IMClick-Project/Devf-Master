# Contador de Tareas con React

Proyecto realizado con React y Vite para practicar los hooks `useEffect` y `useMemo`.

## Objetivo

Crear una aplicación para registrar tareas y el tiempo dedicado a cada una.

## Funcionalidades

- Mostrar la hora actual en tiempo real
- Agregar tareas
- Asignar horas a cada tarea
- Eliminar tareas
- Calcular el tiempo total registrado
- Optimizar el cálculo del total con `useMemo`

## Conceptos utilizados

- React
- Vite
- JSX
- Componentes funcionales
- `useState`
- `useEffect`
- `useMemo`
- Manejo de arreglos
- `reduce()`
- `filter()`
