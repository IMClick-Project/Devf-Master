# Explorador Espacial con React

Proyecto realizado con React y Vite para practicar el ciclo de vida de componentes funcionales.

## Objetivo

Comprender el uso de los hooks `useState`, `useEffect` y `useMemo` mediante un panel de control de una nave espacial.

## Funcionalidades

- Simular el vuelo de una nave
- Controlar la distancia recorrida
- Controlar el combustible
- Registrar planetas visitados
- Calcular la distancia total con `useMemo`
- Practicar montaje, actualización y desmontaje de componentes

## Hooks utilizados

- `useState`
- `useEffect`
- `useMemo`
