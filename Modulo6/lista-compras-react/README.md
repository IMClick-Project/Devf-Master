# Lista de Compras Interactiva

Proyecto realizado con React y Vite para practicar el manejo de estado con `useState`.

## Objetivo

Crear una lista de compras interactiva que permita agregar y eliminar productos, actualizando la interfaz en tiempo real.

## Funcionalidades

- Agregar productos a la lista
- Eliminar productos
- Evitar productos duplicados
- Aumentar la cantidad cuando un producto ya existe
- Agregar productos presionando la tecla Enter
- Actualización dinámica de la interfaz
